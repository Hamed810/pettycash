## Known limitations

1. **`npm run check` still exits non-zero** because `typecheck` includes `tests/Frontend/**`,
   which holds 22 errors. Every one of them is inside `PurchaserFlow.spec.ts` and
   `ManagementReview.spec.ts` — the files T164 and T175 are chartered to rewrite. Fixing them
   here would duplicate those open tasks.
2. **T221 is not complete.** The authentication half is done and the 401s are gone, but the
   fixture half cannot proceed because the endpoints do not yet return 2xx. Authenticated
   traffic exposed these genuine backend defects:
   - `SheetController::create(string $title, string $accountId)`, `TransactionController::correction(int $expectedVersion)`,
     `EvidenceController::upload(string $commandId)`, `EvidenceController::destroy(string $commandId)`
     declare non-nullable scalars. Nextcloud's dispatcher passes `null` when the field is absent,
     producing an unhandled `TypeError` and an **empty 400 body with no OCS envelope** — a direct
     violation of the `ocs.meta.statuscode` contract and Constitution II (preserve contracts).
   - `DbTransactionRevisionRepository::findByTransactionId()` and `DbAuditEventRepository::findByTransactionId()`
     type-hint `int`, but `data-model.md` and `TransactionController` pass UUID strings.
   - `GET /api/v1/accounts` and `GET /api/v1/queues/cost-center` return **500**.
   These belong to the still-open Phase 4/5/13 tasks (T176–T194), not to T221.
3. **`src/l10n.ts` and `l10n/` remain empty.** All 268 call sites now use the canonical
   `t('pettycash', key)` signature, so T119 only has to add the catalog; no call-site rework is needed.
4. `tests/Frontend/__mocks__/components.ts` is still present — unchanged, owned by T158/T215.
