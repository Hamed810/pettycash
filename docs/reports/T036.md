## Verification Details

### Implementation Coverage
The AppDataEvidenceStore now implements all requirements from T036:

| Requirement | Implementation |
|-------------|----------------|
| Opaque `evidence/<transaction-uuid>/<revision>/` keys | `putEvidence()` method creates folder structure |
| 100 MB max file size per FR-074 | `MAX_FILE_SIZE` constant enforced in `put()`, `putEvidence()` |
| Checksums (SHA256) | `getChecksum()` method |
| Safe original filenames | `sanitizeFilename()` private method |
| Draft-delete compensation | `deleteDraftEvidence()` method (idempotent) |

### Architecture Compliance
- Adapter in **Infrastructure layer** per ADR-001
- Implements **Application Port** (`PrivateFileStore` interface)
- Uses only `OCP\Files\IAppData` and `ISimpleFolder`/`ISimpleFile` interfaces
- No business logic - pure technical storage operations

### New Methods Added
- `putEvidence(string $transactionUuid, int $revisionNumber, string $originalFilename, string $content): string` - Store with opaque key
- `readEvidence(string $key): string` - Read by opaque key
- `deleteDraftEvidence(string $key): void` - Idempotent draft deletion
- `getFileSize(string $key): int` - File size validation
- `getChecksum(string $key): string` - SHA256 checksum
- `sanitizeFilename(string $filename): string` - Safe filename handling
