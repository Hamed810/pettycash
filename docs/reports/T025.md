## Verification Details

### Architecture Compliance
- Adapter placed in **Infrastructure layer** (`lib/Infrastructure/Nextcloud/`) per ADR-001
- Implements **Application Port** (`PrivateFileStore` interface) — Domain/Application remain Nextcloud-free
- Uses only `OCP\Files\IAppData` and `ISimpleFolder`/`ISimpleFile` interfaces
- No business logic in adapter — pure technical storage operations

- Constructor injection used throughout — consistent with existing Infrastructure adapters
