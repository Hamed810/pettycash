- All routes registered in `appinfo/routes.php`
- OCS controller base path: `/ocs/v2.php/apps/pettycash/api/v1/`
- `@NoAdminRequired` attribute for purchaser access
- Command ID header required for mutations (`X-PettyCash-Command-ID`)

### Architecture Compliance
- Controllers in **Presentation layer** per plan.md
- Thin adapters - delegate to Application services
- Use `@NoAdminRequired` for purchaser endpoints
- Return OCS-standard `DataResponse`
- Error handling with try/catch returning appropriate HTTP codes
