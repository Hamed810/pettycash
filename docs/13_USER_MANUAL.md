# PROJECT PETTY CASH - USER MANUAL

## Purchaser

Responsibilities:

-   Create Cost Lists
-   Add expenses
-   Upload evidence
-   Submit for approval

## Manager 1

Responsibilities:

-   Review expenses
-   Approve
-   Return
-   Reject

## Manager 2

Responsibilities:

-   Secondary approval
-   Return
-   Reject

## Accountant

Responsibilities:

-   Financial verification
-   Final approval
-   Return incorrect records

## Export

Authorized users can export:

-   CSV
-   Evidence packages

Export follows permission scope.
