# Pettycash Project Instructions
This project uses GitHub Spec Kit with GapCode.
## Spec-Driven Development Rules
Before implementation: 1. Requirements must be captured as specifications. 2. Plans must be created before significant implementation. 3. Tasks must 
be generated from plans. 4. Implementation should follow approved tasks.
## Source of Truth
- Business requirements - .specify/memory/constitution.md - specs/
## Workflow
Use these skills: - speckit-constitution - speckit-specify - speckit-plan - speckit-tasks - speckit-implement
Do not directly implement large features without specification and planning.
